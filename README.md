**Agents, simulations, and physical systems.**

I build software to explore how systems behave: agents making decisions, feedback
loops playing out, and sensors capturing motion. I like making that behavior
observable, so I can understand it, replay it, and build something useful around it.

## Selected work

- **[Rack](https://rackpool.app)** — Stroke tracking for pool players using Apple
  Watch and iPhone. Motion capture on the wrist, live stroke data on the phone, and
  session history to review afterward. Private codebase; public product site.
- **[Meridian](https://github.com/sebastianerz28/meridian-public)** — A multi-agent
  geopolitics simulation where LLM, scripted, and human actors make decisions in a
  shared world. A deterministic, replayable engine for exploring how memory,
  uncertainty, and feedback shape behavior.
- **[BuildDiff](https://github.com/sebastianerz28/BuildDiff)** — A CLI for “why does
  it build here but not there?” Captures two machines' build environments and ranks
  the differences most likely to cause failures.

Mostly working with **C# / .NET · Swift · Elixir / Phoenix · TypeScript · Python**.
